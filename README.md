# 折光纹工具箱 / Refraction pattern master

面向分层插画、卡牌与包装的 **Photoshop 折光纹母版生成工具**：按图层选择纹样、调整线宽与疏密，一键生成独立、可编辑的黑色矢量折光纹母版（PSD），并可逐组导出 PSD / PNG。0.3 起支持**按画面内容自动拆分图层**（实验性）。

> **当前版本：beta0.3**（核心 `2026-09-18c`；实测 Photoshop 2020 / 21.2，Windows / macOS 均可运行）

## 快速开始

### 方式 A：成品包（推荐给使用者，源码不外露）
解压 `折光纹工具箱_发布包.exe` 得到 `折光纹工具箱\` 文件夹（或直接用打包好的文件夹），保持文件夹结构不动：

1. 在 Photoshop 中打开要处理的 PSD（让它成为当前活动文档）。
2. 把 `折光纹工具箱\scripts\折光纹工具箱.jsx`（或同目录的 `折光纹工具箱.lnk`）**拖进 Photoshop 窗口**松手，界面直接弹出（等同以前的 文件→脚本→浏览）。
   备用路径：文件 → 脚本 → 浏览 → 选中该 `.jsx`。
3. 在界面里逐层确认纹样与参数，点"生成"后选择输出目录。

### 方式 B：源码目录（开发 / 维护）
1. 需要 **Adobe Photoshop（ExtendScript/JSX，实测 2020 / 21.2）**。整套文件夹可拷贝到任意盘符、任意（含中文）目录，脚本不写死路径。
2. 换电脑或换 Photoshop 版本后，先运行一次自检：Photoshop → **文件 → 脚本 → 浏览** → `scripts/selftest_core.jsx`（不建文档、不改文件），确认弹窗显示"核心自检 通过"。
3. 打开分层源 PSD，运行 **文件 → 脚本 → 浏览** → `scripts/generate_refraction_gui.jsx`，在列表里逐层确认纹样与参数；右侧小视窗会显示当前纹样的示意图。可勾选 **「读取画面内容」**（默认开）让"建议当前层 / 建议全部"先分析图层画面（每层约 1–2 秒），按画面走向与形态选纹样、修方向。点"生成"并选择输出目录。
4. 需要逐组文件时，打开生成的母版，运行 `scripts/export_groups.jsx`。

## 版本记录

### beta0.3（核心 2026-09-18c）
- **新增「内容拆分」（实验性）**：按画面内容把一个大图层自动拆成命名子图层——
  - 人物类：轮廓线稿 / 脸部 / 头发 / 衣物 / 皮肤 / 珠宝装饰；
  - 景色类：天空 / 云 / 山脉 / 森林 / 水面 / 地面 / 建筑 / 墙面 / 廊柱；
  - 室内类：墙面 / 书架 / 垫子 / 地毯 / 廊柱 等。
  原图层变成一个组、组内保留隐藏的原始备份，子层按内容命名并**归位到原图层的位置**（不改变折光层序）。
  - GUI：每层「内容拆分（实验性）」勾选 + 模式下拉（自动 / 人物 / 景色 / 室内）+「执行拆分（实验性）」按钮；**执行前自动另存 `-拆分前副本.psd`**（asCopy，不影响当前文档），拆完自动重建图层列表。
  - 管线：透明底渲染 → k-means 聚类 → 并查集连通域 → 区域特征（颜色/位置/细线/纹理/长宽比）→ 规则归类 → 掩码放大回全画布 → 建子层（用"编辑→剪切"清像素，因为 `ArtLayer.clear()` 会无视选区整层清空）。
- **拆分分析提速约 12 倍**（595 s → 约 50 s/层）：发现并绕开 **ExtendScript 大数组性能悬崖**——数组元素超过约 10 万后逐元素读写会灾难性变慢（实测 262144 项数组读一遍要 5 分钟）；量化色缓存降为 32768 项、洪泛改并查集、区域统计改平行数组、掩码 BMP 改"行程拼行"（写盘 51.8 s → 21 ms）。
- **分类修正**：新增「云」（上半部浅色低饱和低纹理大块，判定先于"墙面"）与「山脉」；皮肤判定加亮度上限、新增"身体走廊"约束（离脸太远的肤色/布料不再算人物）；景色分支不再误分书架/垫子/地毯。
- **修复**：拆分中"合并可见图层"错误弹窗卡流程（全程关闭交互对话框 + 可见层数护栏）；拆分组跑到图层栈最前导致折光层序错（组归位）；预览图缺失时会把整个宏打挂。
- **打包与授权**：`tools/build_bundle.py` 把核心+GUI 合成**单文件加密 `.jsx`**（拖进 Photoshop 即运行，源码与纹样库不外露）；`tools/build_sfx.py` 产出**带 logo 图标的 7-Zip 自解压发布包**；新增 `LICENSE.txt`（版权 gilsophia，禁止二改二传）。
- 实测：012-C（1748×3402@600）拆分 background → 天空 10.9% / 云 9.1% / 墙面 / 轮廓线稿 等；生成 23 组 / 35 形状层 / 0 失败 / `MASTER_QA PASS`，总耗时 9 分 25 秒（其中区域裁剪合计仅 8.8 s）。011 女王层拆分 → 衣物 67.6% / 其他 13.3% / 线稿 6.6% / 皮肤 1.4%。
- 已知局限：米金/奶油色系的装饰背景在「自动」模式下仍可能误检"脸"而走人物规则，此时把该层模式手动改为「景色」或「室内」即可；天空/云边界仍是 256px 分析图放大（偏软），留待长期优化。

### beta0.2b（核心 2026-09-18a）
- **大层生成/裁剪提速**：区域裁剪改为"细网格奇偶栅格"（与逐点判定数学等价），区域外元素在生成阶段直接跳过；合成 A/B 140 s → 1.4 s，010 的 Velvet_S 生成 108.6 → 43.0 s、裁剪 27.0 → 2.8 s。
- **`content_flow` 随形流场加密**：中心距与 `flow` 对齐（线宽+中隙）、种子加密、只在空区起笔（少碎点）、分段阈值放宽到 144°；预览与总览同步更新。
- 实测：011（5 层 @1200ppi）**5 组 / 0 失败 / `MASTER_QA PASS`，总耗时 6 分 19 秒**；同源 010-B 为 9 分 18 秒，content_flow 线数 974 → 3093。
- 备注：`content_flow` 大层的几何生成仍是耗时大头（ExtendScript 数组开销），扁平数组改造留待后续。

### beta0.2（核心 2026-09-17d）
- 新增纹样 **`content_flow`（随形流场）**：沿画面内容走向积分出流线，方向随形体无缝变化、按段收尾；GUI 下拉与预览图同步（现 29 种）。
- 纹样建议升级：名称规则给出**候选集**，再按全库用量轮换、并让相邻区块尽量不用同一种/同一族纹样（避不开时自动换 45° 方向）。
- 新增可选 **「读取画面内容」**：分析图层画面的主走向、方向一致度、弯折度、径向性与细节密度，用于选纹样与修正方向。
- 稳定性修复：剪贴蒙版层取样为空、稀疏大块层预算误报、失败层导致整次生成中止、退化小区域卡死、大面积高分辨率软渐变层转路径卡死（转路径前自动平滑轮廓，实测从卡住 17 分钟降到 2 秒）。
- 实测：010 全层版 87 层 / 59 组 / 0 失败（约 20 分钟）；精简版 5 层 / 4 组 / 0 失败（约 9 分钟）；两版均 `MASTER_QA PASS`。

## 注意

- **不要把 `scripts/` 里的文件拆开**：入口脚本用自身路径定位同目录的 `refraction_core.jsx`。
- **保留 `texture-preview/` 与 `scripts/` 的相对位置**：GUI 用该目录中的“中文名-英文键名.png”显示纹样预览；预览是示意图，调整线宽与间隙不会实时重绘。缺少预览图时，GUI 会显示提示，仍可生成纹样。
- **打包版使用**：拖 `scripts\折光纹工具箱.jsx`（或 `折光纹工具箱.lnk`）进 Photoshop 窗口即可运行；`.jsx` 在系统里默认关联 After Effects，**不要双击**。拖 `.lnk` 若没反应就直接拖 `.jsx`。

- `job.json` 模式里的 `source_psd` / `output_dir` 是绝对路径，换机器要改；GUI 模式不需要。
- 生成过程与结果说明见 `zg_progress.txt`（逐层进度、蒙版简化、耗时）和 `master_report_*.txt`。
- 详细设计规则、参数、验收流程与已知限制见 `references/` 与 `折光纹工具箱_功能说明.md`。
